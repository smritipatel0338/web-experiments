Inline elements: - Do not start on a new line - Take up only as much width as needed - Flow within the same line as surrounding text - Are used to format small pieces of content Examples are- -span — inline container -strong — makes text bold and is inline

Block elements are those that: - Always start on a new line - Occupy the full width available (stretch across the page) - Can contain other block elements and inline elements - Are used to create the main structure of a webpage Examples are- - p — paragraph - div — generic container - h1 — heading
